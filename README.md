A painting tool made for the playstation 2.

You can draw, change colors, use stickers, resize the canvas, change drawing tools

## Features

- **Brush**
- **Marker**
- **Eraser**
- **Fill tool**
- **Color selection**
- **Adjustable tool sizes**
- **Stickers**
- **Adjustable sticker size**
- **Canvas resizing**
- **New canvas**
- **Clear canvas**
- **Pan and zoom**
- **Stabilizer**
- **Multiple movement options**

Ps2_Paint uses the playstation 2 controller only, No mouse support

## Compatibility

Can be played both on a real playstation 2 or the pcsx2 emulator
